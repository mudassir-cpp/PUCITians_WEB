PUCITians — Academic Hub for PUCIT Students (Web)

Problem Statement

Academic life at PUCIT is scattered across many platforms: lecture slides live on teachers' data / \\printsrv, TA marksheets are spread over multiple Google Docs, past papers and lab materials sit in senior students' GitHub repos, and announcements are buried in chats and Drive links. Students waste time searching, miss updates, and have no privacy-aware way to view their marks. There is no single campus-focused web platform that brings resources, joinable classes, limited mark visibility, and student knowledge together.

Proposed Solution

PUCITians is a web application (hosted at pucit.app, a domain already acquired for the project) that centralizes PUCIT academic activity in one place. Users sign in with their @pucit.edu.pk Google account. Admins create classes and assign teachers; students join classes through invite links (e.g. pucit.app/<id>). Each class provides a Classroom-style feed of materials and announcements, a curated resource hub (slides, Drive links, past papers and labs from senior GitHub repos), and a privacy-aware TA marksheet where students only see the fields they are allowed to see (e.g. lab presence, marks shared on comments). A student-run wiki/blog, moderated by admins, lets campus knowledge live in one platform instead of being lost across chats, Docs, and Drives.

User Roles

  • Admin — creates classes, assigns teachers, approves student wiki/blog posts, manages users.
  • Teacher / TA — posts materials and announcements, manages the class marksheet, curates resources.
  • Student — joins classes via invite link, views materials and permitted marks, submits wiki/blog drafts.

Key Features

  • PUCIT-only login — Google OAuth restricted to @pucit.edu.pk accounts
  • Class management — admins create classes, add teachers; students join via link (pucit.app/<id>)
  • Classroom-style feed — materials, announcements, and resource links per class
  • Resource hub — slides, Drive links, past papers and labs from senior GitHub repos
  • Privacy-aware TA marksheet — students see only permitted fields
  • Student wiki/blog — drafts by students, published after admin approval
  • Role-based dashboards — my classes, allowed marks, pending/approved posts
